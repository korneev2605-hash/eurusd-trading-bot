# EUR/USD Bot - Windows 11 Полная Инструкция

## 🚀 Быстрый Старт (3 шага)

### Шаг 1: Загрузить Проект
1. Перейди на: https://github.com/korneev2605-hash/eurusd-trading-bot
2. Нажми **Code** → **Download ZIP**
3. Распакуй ZIP в папку, например: `C:\eurusd-bot\`

### Шаг 2: Собрать EXE (один раз)
1. Открой папку проекта (`C:\eurusd-bot\`)
2. **Двойной клик** на `install_and_build.bat`
3. Дождись сборки (~5-10 минут)
4. Скрипт сам скачает Python и соберёт EXE
5. Готовый файл появится в папке: `dist/eurusd_bot.exe`

### Шаг 3: Запустить Бота
1. Двойной клик на `dist/eurusd_bot.exe`
2. Откроется консоль с сигналами
3. Бот работает каждый час автоматически
4. Закрывай окно консоли чтобы остановить

### 🛠️ Шаг 2: Сборка EXE

#### Способ A: Автоматическая сборка (самый простой)
1. Открой папку проекта: `C:\eurusd-bot\`
2. Найди файл `install_and_build.bat`
3. **Двойной клик** на него
4. Откроется чёрное окно (Command Prompt)
5. Скрипт будет:
   - ✅ Проверять наличие Python
   - ✅ Если нет → скачивать портативный Python 3.11
   - ✅ Устанавливать зависимости
   - ✅ Собирать EXE файл
6. Дождись сообщения **"Build complete!"**
7. Нажми любую клавишу

**Результат:** В папке `dist/` появится файл `eurusd_bot.exe`

#### Способ B: Если у тебя уже установлен Python 3.10+
1. Открой Command Prompt в папке проекта:
   - Shift + Правый клик в папке → "Открыть PowerShell здесь"
2. Выполни команду:
   ```bash
   python install_and_build.bat
   ```
3. Дождись завершения

## 📊 Как читать сигналы

### 🟢 BUY (Покупка)
- **Условия:**
  - Цена выше SMA(20), SMA(20) выше SMA(50)
  - RSI > 52 (восходящий тренд)
  - MACD пересёк Signal Line вверх (бычий сигнал)
- **Что означает:** Тренд вверх, хороший момент для входа в лонг

### 🔴 SELL (Продажа)
- **Условия:**
  - Цена ниже SMA(20), SMA(20) ниже SMA(50)
  - RSI < 48 (нисходящий тренд)
  - MACD пересёк Signal Line вниз (медвежий сигнал)
- **Что означает:** Тренд вниз, хороший момент для входа в шорт

### 🟡 HOLD (Ждать)
- **Условия:** Ничего из выше описанного не выполняется
- **Что означает:** Рынок неопределённый, ждём более чётких условий

## 🔧 Что дальше?

### Запуск каждый день
Просто двойной клик на: `C:\eurusd-bot\dist\eurusd_bot.exe`

### Создать ярлык для быстрого запуска
1. Перейди в папку `C:\eurusd-bot\dist\`
2. Правый клик на `eurusd_bot.exe` → **Отправить** → **На рабочий стол (создать ярлык)**
3. Теперь на рабочем столе ярлык, двойной клик = запуск

### Запуск от администратора (если нужно)
1. Правый клик на `eurusd_bot.exe`
2. **Запустить от имени администратора**

### Запуск в фоне (продвинутый вариант)
Создай файл `run_bot_hidden.vbs` в папке проекта:
```vbscript
Set objShell = CreateObject("WScript.Shell")
objShell.Run "dist\eurusd_bot.exe", 0, False
```
Двойной клик запустит бота в фоне (без видимого окна)

## ⚠️ Решение проблем

### Проблема: "Python not found"
**Решение:**
1. Удали папку `python_portable` если она есть
2. Заново запусти `install_and_build.bat`
3. Позволь скрипту скачать Python

### Проблема: "No data available"
**Решение:**
- Проверь интернет соединение
- Yahoo Finance может быть перегружен — жди 5 минут
- Бот автоматически повторит попытку

### Проблема: EXE не запускается
**Решение:**
1. Открой Command Prompt
2. Перейди в папку: `cd C:\eurusd-bot\dist\`
3. Выполни: `eurusd_bot.exe`
4. Посмотри ошибку на экране

### Проблема: "Permission denied"
**Решение:**
- Запусти `install_and_build.bat` от администратора:
  1. Правый клик на файл
  2. **Запустить от имени администратора**

### Проблема: Антивирус блокирует
**Решение:**
- Это нормально для PyInstaller собранных файлов
- Добавь исключение в антивирус:
  - Путь: `C:\eurusd-bot\dist\eurusd_bot.exe`
  - Или вся папка: `C:\eurusd-bot\`
